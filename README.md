# Tengxiang Lin Academic Website

Personal academic website for Tengxiang Lin, redesigned as a modern Hugo academic CV portfolio inspired by the HugoBlox Academic CV / Hugo Academic structure.

- Local build: `hugo --gc --minify`
- Local preview: `hugo server --bind 0.0.0.0 --baseURL http://localhost:1313`
- Production URL: <https://tengxianglin.github.io/>

The site intentionally avoids demo authors, demo publications, stock placeholder content, and unverified publication metadata.
